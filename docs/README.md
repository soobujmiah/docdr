# Documentation

This repository is classified as `android-app` under the canonical standard. The
engineering contract for that type is `standards/repository-types/android-app.md`
in `soobujmiah/skb`.

## Documentation areas for this type

| Directory | Contents |
|---|---|
| `product/` | What the project is for, who it serves, and its current state |
| `architecture/` | Structure, boundaries, and the reasoning behind them |
| `development/` | How to build, run, and contribute |
| `testing/` | What is tested, how, and what is deliberately not covered |
| `security/` | Threat model, data handling, and secret handling |
| `operations/` | Deployment, monitoring, and maintenance |

A directory exists only when it holds real content. Empty directories are not
created to satisfy a checklist.

## Rules

- Maintain this index when a documentation area is added, removed, or renamed.
- Operational state (build/test status, phases, current progress) is generated by
  the repository's own tooling and is read from `.repo/STATUS.md`; it is not
  restated as prose here.
- Decisions are recorded as ADRs under `docs/adr/` where the type requires them,
  using the format in `standards/repository-research-and-adr.md`.
